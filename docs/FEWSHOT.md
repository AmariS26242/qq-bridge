# few-shot 正例库：怎么给「好回复」的素材

小鲸鱼每轮被唤醒时，桥接会按当轮群聊内容从库里挑 2~4 条最像的「真人接话」样例，注入唤醒提示词。它学的是**语气、长度、接话角度**，不是内容照抄。

素材目录：`persona-lib/fewshot/`

- `raw/*.md` —— 手写的样例（人读友好，推荐先加这个）
- `inbox/*.txt` —— QQ 导出的聊天记录（整段搬运，脚本自动配对）
- `examples.jsonl` —— 脚本生成的索引，别手改

## 方式一：手写 .md（最省事）

在 `persona-lib/fewshot/raw/` 下任意新建 `.md`，按下面格式写，一个空行一组：

```markdown
# 标签1 标签2
群友：我分手了
我：？ 谁提的

群友：最近好累
我：多大了 还累
```

规则：

- `# ` 开头的行是这一组的标签（空格分隔），会参与相似度匹配（标签也能当场景名命中，比如 `冷场`）
- 「群友：」「对方：」「他：」「她：」= 别人说的；「我：」「你：」= 小鲸鱼该说的
- 「注：」「场景：」= 场景说明，不当作某个人说的话（渲染成「（…）」），适合「群里安静了二十分钟」这种没有具体发言的场合
- 每组**最后一行**必须是「我：」，前面几行是上下文
- 回复要像群聊，短、口语、可以带「？」「…」；别写超过 30 字的小作文
- 反例（AI 腔）也可以写成一组，标签加 `反例`，导入后仍会参与相似度但不学内容——目前建议只在 `--dry` 里看，不要入正式库

## 方式二：QQ 导出的 txt（量大、最真实）

1. QQ 消息管理器 → 选中会话 → 右键「导出消息记录」→ 选 **文本格式(.txt)**
2. 丢进 `persona-lib/fewshot/inbox/`
3. 导入时**必须告诉我你在导出文件里的昵称**（脚本靠它区分「谁是我」）：

```powershell
cd "<repo>"
node scripts/fewshot-import.mjs --me "你的QQ昵称"
```

不加 `--me` 或昵称对不上时，脚本会列出文件里出现的发送者名字并报错，不会瞎配对。

导入规则：相邻两条不同人的消息配成「上一条→我的回复」；只收 ≤40 字的回复；链接、长文、纯表情跳过。

### 粘贴式记录（QQ 里选中消息复制出来的形状）

除了带时间戳的导出文件，`inbox/` 里也接受这种更省事的格式，脚本会自动识别：

```
我：在干嘛
对方：刚下班 累死
我：要不要一起吃面
对方：算了 不想动
```

规则：`名字：内容` 一行一条，多行消息自动并入上一个说话人；`我`（或 `--me` 指定的昵称）代表你，其余名字代表对方。

### 为什么 .bak 不行

QQ 的「聊天记录备份」导出的 `.bak` 是 zip 包，里面是头部伪装成 `SQLite header 3` 的**加密**数据库，只有 QQ 自己能导入还原，外部工具读不到明文。导入器会识别它并直接报错，不会误读。要导出可解析的内容，请走上面的「导出消息记录 → 文本格式」，或者在聊天窗口里选中多条消息复制成「我：…」格式。

## 方式三：直接贴给我

在对话里贴：

```
对方：在吗
我：说事
```

我会帮你补标签、去掉不合格的组、写进 `raw/`。

## 导入、检查、回滚

```powershell
node scripts/fewshot-import.mjs --dry     # 只看解析结果，不写文件
node scripts/fewshot-import.mjs           # 正式导入（自动去重）
node scripts/fewshot-import.mjs --stats   # 看库里现在有多少条
```

或打开控制台（http://127.0.0.1:3100）调 `GET /api/roles/fewshot` 看统计，`POST /api/roles/fewshot/import` 触发一次导入。

查「此刻某条群唤醒会注入哪几条」：

```powershell
# 只读预览（不写轮换状态）
curl "http://127.0.0.1:3100/api/socialV2/wake-prompt?token=<console-token>&key=group:123456"
```

返回里的 `prompt` 含【接话参考】块；`GET /api/roles/fewshot?key=group:123456` 则单独给出这条群的预览块和命中的场景。

回滚：删掉新增的 `raw/*.md` / `inbox/*.txt`，再跑一次导入；或在 `config.json` 把 `style.fewshot.enabled` 设为 `false`。

## 预算

- 每轮最多 4 条、总计 ≤900 字符（`config.json` → `style.fewshot`）
- 最近 12 条用过的会回避，不会每轮都看到同一组
- 当轮没有足够相似的样例时，只给 1 条兜底样例保持语气；库为空时完全不注入
- 改完 `config.json` 或素材后：跑一次导入 → 重启桥接（控制台 `/api/roles/fewshot` 也支持热触发导入）
