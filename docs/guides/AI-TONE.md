# 去 AI 味：出站文本后处理（aiTone）

> 目标：让 QQ 端的回复不像 AI 写的。分三层拦截，**提示词只是第一层，管不住已生成的句子**。

## 三层结构

| 层 | 位置 | 作用 | 改完怎么生效 |
| --- | --- | --- | --- |
| ① 人格卡 | `roles/小鲸鱼.md` §六/§七 | 写清黑名单 + 正反例（每条消息注入） | 立即（桥接每条消息重读） |
| ② 仿真提示词 | `dsh/agent-presets/qq-chat-v2/agent.cordis.yml` | 行为层：别当心理咨询师、分条节奏、拒绝有求必应 | `node scripts/build-agent-preset-patches.mjs` → 重启 DSH |
| ③ 发送层后过滤 | `src/ai-tone.js` ← `src/bridge.js` | 硬过滤：词句删改、Markdown 清洗、句号剥离 | 重启 qq-bridge（`node qqbot.mjs up`） |

第 ③ 层是唯一有强制力的：模型说了「这话听着挺沉的」，提示词拦不住，但发送前会被删掉。

## 接入点（改代码时别漏）

- `src/bridge.js` `sendToQQ(key, msg)` —— 一代 + 所有系统播报之外的通知
- `src/bridge.js` `sendMessagesV2(...)` —— 二代 MCP 发送、burst、定时提醒
- `src/bridge.js` 空间分隔的 v1 burst 发送循环
- 统一入口 `deslopOutgoing(key, raw)`：读 `cfg.aiTone`，跳过 `⚠️/⏳/系统` 开头的告警，命中时写日志
  `去AI味 <key> [命中规则] 原文 → 清洗后`
- 清空成空串时**整条不发**（纯 AI 腔填充不该变成空气泡）

## 配置（`config.json` 的 `aiTone`）

```json
"aiTone": {
  "enabled": true,
  "stripTrailingPeriod": true,
  "stripAgreeOpener": true,
  "logHits": true,
  "extraPhrases": [],
  "keepPhrases": []
}
```

- `enabled: false` 一键关掉。
- `extraPhrases`：追加屏蔽词，元素可以是纯字符串（删除），也可以是 `"原词=>替换"`。
- `keepPhrases`：豁免词（群名、人名、梗），先占位保护再还原。
- `fallback`：整条被删空时的兜底文本，默认 `嗯`（桥接层通常直接跳过不发送）。
- `normalizeDash`：把 `——` 换成 `，`，默认关（真人也会用破折号）。

## 内置规则（`src/ai-tone.js`）

- `RULES`：约 40 条正则，覆盖心理师腔（「这话听着挺X的」「听起来你」「我理解你的感受」「允许自己」「稳稳地接住」）、
  总结拔高（「值得注意的是」「综上所述」「让我们来看看」）、客服腔（「希望对你有帮助」「有问题随时问我」）、
  Markdown 残留（`**加粗**`、`## 标题`、`- 列表`、`` `代码` ``）、程度副词（「非常X」→「X」）。
- `WORD_MAP`：互联网黑话 1:1（赋能→帮、打造→做、闭环→完整流程…）。
- `FORMAL_MAP`：书面腔→口语腔（因此→所以、例如→比如、以及→和、是否→是不是、进行了讨论→讨论…）。
- `AGREE_OPENER_RE`：句首确认式开场「行，」「好的，」「没问题，」「收到，」——客服接单口气，删前缀直接接内容。
  只吃「词 + 逗号」形态，单独一个「行」和「行吧，」不动。
- `FLAG_ONLY`：只记日志不改写的词（复盘、对齐、沉淀…）。
- `PUNCT_FIXES`：删词后留下的句首逗号、连续标点等修补。

**执行顺序**：Markdown 清洗 → 文体规则 → 词表替换 → 豁免词还原 → 标点修补 → 句号剥离。
Markdown 必须最先跑：否则 `**希望**对你有帮助` 里的「希望」前面是星号不是标点，第一次过滤会漏掉、要跑第二遍才干净（幂等性测试守这条）。

## 已知限制

- 只处理**文本段**；表情包、图片、语音不适用。
- 正则只能抓句式模板，抓不到「把对方的话总结成情绪形容词」的所有变体——这类靠人格卡和预设提示词的正反例。
- 人格卡注入上限 `role.maxInjectChars = 6000`，当前 §六/§七 扩写后约 5600 字符，**余量只剩 ~400**，再加内容要先精简别处。

## 其他降 AI 感的办法（已落地 / 可继续）

已落地：

1. 长短句交替、一条一个意群、默认 1~2 条（预设【分条与节奏】）。
2. 允许漏看/迟到/离场，允许不回复（预设【像真人一样漏看/迟到/离场】）。
3. 拒绝有求必应，可以反问/装傻/拒绝（预设【反 AI 味：拒绝有求必应】）。
4. 别当心理咨询师：共情是反应不是宣布（预设【别当心理咨询师】）。
5. 短句不写句号、不用 Markdown（ai-tone 后处理）。
6. 表情包按语境发、不总拿表情当唯一回复（预设【表情包】）。

还可继续（按性价比）：

- **随机小失误**：0.1~0.2 概率漏一个「了」或错个同音字。最像真人，但会牺牲少量可读性，需要开关。
- **打字延迟**：按字数给 1.5~4 秒随机延迟（已有 burst 间隔，可再随机化）。
- **长消息一刀切两段**：AI 偏爱一条说完，真人常分两条补（burst 已有，可提高长句拆分概率）。
- **禁用句首连接词**：「其实」「确实」「说真的」开头的比例越高越像 AI，可做概率性删除。
